# Subject examples

This directory is for optional subject-specific examples. Examples do not add permissions or tools.

Add a file when a real course case reveals a reusable teaching pattern, for example:

```text
examples/linear-algebra.md
examples/circuits.md
examples/programming.md
```

Each example should state:

- the course/context it came from, with no personal data;
- what the learner struggled with;
- which mode (`explain`, `hint`, `check`, `review`) helped;
- the fact/inference boundary.

Do not add a new tool, a website adapter, or a database table for a subject example.
