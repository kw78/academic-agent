# Academic Agent v0.2.0

发布日期：2026-10-28

这是一个以“接入闭环 + 可靠性 + 应用层收口”为主的版本。数据库迁移与事件格式没有变化，可直接覆盖安装。

## 主要变化

### 接入与发现

- **引导录制**：连接页“登录并录制”在登录浏览器内只读采集 `xhr/fetch/document` 响应，原始 body 只留在宿主样本库（60 分钟、80 条），模型只拿到接口清单（方法、脱敏 URL、集合路径、嵌套字段、分页参数、`sampleId`）。
- **空数组与参考数据**：JSON 数组改为枚举所有节点并返回精确路径；空数组保留为 `empty` 集合；学校/地区等参考数据标记为 `reference`，不会被当成首选列表。
- **声明式只读 POST**（ADR 0016 / 0021）：Manifest 支持 `method: "POST"`，JSON body（模板、≤16 KB）或扁平表单 `bodyFormat: "form"`；可用 body 内分页。除 `x-requested-with: XMLHttpRequest` 外不接受自定义头，不支持 multipart。
- **登录与出口判定**：只有 HTML 响应参与登录页判断，JSON 路径含 `/login` 不再误判；网络出口失败归类为 `AdapterEgressError`；代理 TUN 的 fake-IP 仅在全部解析结果落在 `198.18.0.0/15` 时放行。

### 可靠性

- **真实来源定时同步**（ADR 0017）：每个可同步来源拥有 `source.sync.<sourceId>` 作业，创建/启用/恢复时建立，归档/禁用/删除时暂停；未验证会话只记录 `skipped: auth-required`，设置页周期同时作用于 fixture 与全部来源。
- **生命周期竞态**：运行期间暂停/恢复或改配置不会被完成回写覆盖；消费者卸载后同批次不再收到后续事件；`close()` 先停止接收、等待在途任务，再关闭存储。
- **完整应用备份**（ADR 0018）：`backup-app` 生成数据库 + `materials/` + SHA-256 清单；`restore-app` 先校验全部哈希再恢复，失败不留下半成品。
- **多步骤恢复语义**（ADR 0019）：课程删除遇到 `CONFLICT` 重读重试，持续冲突时不删除课程；候选启用失败回滚原激活版本。

### 界面

- 导航改为“日常学习 / 管理”分组，总览改称“今天”，新增课程工作区与跨页课程上下文。
- 今天/逾期按业务时区计算；任务与来源事项、本地完成与学校提交状态分开显示。
- 计划候选与当前计划可对照；归档旧计划后候选仍可重试确认；键盘焦点与深链接滚动更稳定。

### 架构

- 新增宿主无关包 **`@academic/application`**（ADR 0020）：`createAcademicApp`、备份恢复与来源写入规则（创建/更新/归档/恢复/删除/登录/连接/同步全部）集中在这里；CLI、UI、Agent 工具只做校验、授权与展示。
- DSH Host、UI 与插件改为依赖 `@academic/application`；`@academic/cli` 仅保留命令入口与兼容 re-export。

## 工具

DSH 工具数更新为 **25**（新增 `academic_crawl_source`、`academic_list_capture_endpoints` 等录制/抓取能力）。

## 升级

数据结构未变，替换插件后重启 DSH 即可：

```bash
dsh plugin --profile desktop remove @academic/dsh-plugin @academic/dsh-ui
dsh plugin --profile desktop add \
  @academic/dsh-plugin@0.2.0 \
  @academic/dsh-ui@0.2.0
```

本地 tarball（GitHub Release 附件）：

```bash
dsh plugin --profile desktop add \
  /path/to/academic-dsh-plugin-0.2.0.tgz \
  /path/to/academic-dsh-ui-0.2.0.tgz
```

> Desktop 使用 link 包时，重建 `lib/` 后必须完全退出并重启 DSH；仅刷新页面不会加载新的工具描述。

## 已知限制

- npm registry 发布仍等待本机 `npm login` 与 `@academic` scope；本版本通过 GitHub Release、市场索引与本地 tarball 分发。
- multipart、任意自定义请求头、动态签名、XPath/XML 与任意 JavaScript 仍不支持；超星/智慧树的表单接口已具备 Manifest 与回放能力，真实登录录制仍需验证。
- Blackboard 真实考试/测验样本仍缺失；Desktop 文件级 HMR、真实 Session 生命周期与完整审批 UI 未专项验收。
- 扫描版 PDF 无 OCR；渲染后 DOM / iframe 采集尚未实现。
