# Academic Agent v0.1.0 Release Notes (draft)

状态：**GitHub Release 已发布源码与 tarball；npm 包尚未发布（需要 npm 认证）。**

## 亮点

- 单用户、本地优先的学业助手：课程、来源事项、学习任务、计划与提醒由事件溯源内核维护，SQLite Event Store 与核心投影同事务。
- 许可证：Apache-2.0（根目录 `LICENSE` / `NOTICE`）。
- DSH 集成：`@academic/dsh-plugin` 提供 23 个 Agent 工具（默认只读，写入需可信宿主逐次授权）；`@academic/dsh-ui` 提供“学业”面板，包含总览、任务、计划、连接、资料、自动化与设置。
- 数据源：通用网站会话登录、凭据与元数据分离、Windows DPAPI、Blackboard 只读 Adapter、声明式 Manifest Adapter、候选验证/启用/回滚。
- 课程资料库：本地文件按 sha256 存储，SQLite 只存元数据/分块/FTS5；支持 PDF/HTML/Markdown/TXT/PPTX/DOCX、文件/文本/URL 导入、检索引用、删除与索引重建；单文件上限 80 MB。
- 课程身份去重：同一学期同名课程只保留一门，来源别名映射；历史重复可用设置页或 `course merge-duplicates` 合并，事项/资料/优先级迁移后关闭重复课程。
- 教学 skill：`skills/academic-tutor` 提供 explain/hint/check/review 模式，要求先检索资料并引用标题/页码；资料不足时明确说明。
- 常规同步、去重、提醒与基础规划不调用 LLM。

## 兼容性

- Node.js **≥22.12.0**（本轮验证环境 v22.23.2）。
- DSH **0.2.1-rc.3**（插件 peer 范围 `>=0.2.0-rc.1 <0.3.0-0`）。
- 系统凭据库当前为 **Windows DPAPI**；其他平台需要替换 Credential Vault 实现。

## 安装（源码）

```bash
npm ci
npm run typecheck
npm test
npm run build:dsh
npm run build:ui
```

DSH 独立 profile（从源码工作区安装）：

```bash
dsh plugin --profile academic add <path-to-repo>/packages/academic-dsh-plugin
dsh plugin --profile academic add <path-to-repo>/packages/academic-dsh-ui
```

默认数据库：`$DSH_HOME/academic-agent/academic.db`。可用 `ACADEMIC_AGENT_DB` 覆盖。

本轮已用 `npm pack` 生成的 tarball 在临时 DSH profile 中实测：host/tools 加载，`tools=23 registered=true`，只读成功，写入返回 `FORBIDDEN`。GitHub Release 已附加 tarball；npm 发布尚未执行。

## 已知限制

- 未实现 OCR；扫描版 PDF 只能保存原件，不能检索正文。
- 自动多页发现未实现；附件导入只扫描用户给出的单个课程页。
- DSH 文件级 HMR、真实 Session 生命周期与完整审批 UI 未验证。
- Blackboard 真实考试/测验样本缺失；考试/测验仍以脱敏 fixture 验证。
- `node:sqlite` 仍为实验性 API；升级 Node/DSH 需要重新运行验证命令。
- 备份命令只备份 SQLite；整库迁移需同时复制数据库同目录的 `materials/`。
- npm 当前未登录，`@academic` scope 的归属/发布权限未确认；npm 发布不得在确认前执行。
- 这两个包面向 DSH profile 加载；普通 npm 项目直接安装时，可选 DSH peer 可能触发 npm ERESOLVE，本轮干净安装使用 `--legacy-peer-deps` 验证。
- GitHub Release 下载的 tarball 可直接用 `dsh plugin --profile … add <tgz>` 安装。
