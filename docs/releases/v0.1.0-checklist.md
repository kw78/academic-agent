## B. 阻断项（发布前必须解决）

1. **未提交修改**
   - 当前 `main` 有大量未提交修改（含本轮与并发会话的改动）。tag 不会包含未提交文件。
   - 需先审阅并提交所有发布内容，再打 tag。
2. **npm 未登录，scope 未确认**
   - `npm whoami` 返回 `ENEEDAUTH`。
   - `@academic/dsh-plugin` / `@academic/dsh-ui` 当前未发布；`@academic` scope 归属未知。
   - 若 scope 不可用，需要改包名并同步：
     - `packages/academic-dsh-plugin/package.json`
     - `packages/academic-dsh-ui/package.json`
     - `packages/academic-dsh-plugin/cordis.patch.yml`
     - `packages/academic-dsh-ui/cordis.patch.yml`
     - 文档与安装命令
3. **clean install peer resolution**
   - 干净目录直接 `npm install` tarball 时，npm 对 DSH 可选 peer 选择产生冲突；本轮用 `--legacy-peer-deps` 完成验证。
   - DSH 运行时本身提供 peer，发布说明需明确“安装到 DSH profile，不单独 npm install 到普通项目”。

## C. 人工执行命令（确认后）

### 1. 提交并复核

```bash
git status --short
git diff
git add <需要发布的文件>
git commit -m "chore(release): prepare v0.1.0"
npm ci
npm run typecheck
npm test
npm run build:dsh
npm run build:ui
```

### 2. Git tag 与 GitHub Release

```bash
git tag -a v0.1.0 -m "Academic Agent v0.1.0"
git push origin main
git push origin v0.1.0
gh release create v0.1.0 \
  --title "Academic Agent v0.1.0" \
  --notes-file docs/releases/v0.1.0.md
```

### 3. npm 登录与 scope

```bash
npm login
npm whoami
npm view @academic/dsh-plugin version   # 确认 scope 权限/是否已存在
```

如果 `@academic` 不可用，先决定新包名并完成改名、重新 build、重新 pack；不要直接 publish 未改名包。

### 4. 生成并复核发布包

```bash
mkdir -p dist/release
(cd packages/academic-dsh-plugin && npm pack --pack-destination ../../dist/release)
(cd packages/academic-dsh-ui && npm pack --pack-destination ../../dist/release)
sha256sum dist/release/*.tgz > dist/release/SHA256SUMS
```

### 5. 发布（仅在人工确认后）

```bash
npm publish dist/release/academic-dsh-plugin-0.1.0.tgz --access public
npm publish dist/release/academic-dsh-ui-0.1.0.tgz --access public
npm view @academic/dsh-plugin@0.1.0 version
npm view @academic/dsh-ui@0.1.0 version
```

不要发布 `@academic/contracts`、`@academic/cli`、`@academic/materials` 等内部包；它们已被打进两个发布包的 bundle。

### 6. 发布后回归

```bash
# 干净临时 profile（包来自 registry 或本地 tgz）
release_home="$(mktemp -d)"
DSH_HOME="$release_home" dsh plugin --profile release-test add \
  @academic/dsh-plugin@0.1.0 @academic/dsh-ui@0.1.0
DSH_HOME="$release_home" ACADEMIC_AGENT_SELFTEST=1 \
  ACADEMIC_AGENT_DB="$release_home/academic.db" \
  dsh --profile release-test academic --json "hello"```
