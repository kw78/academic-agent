# Academic Agent v0.1.1

发布日期：2026-10-28

这是一个以接入能力为主的补丁版本：修复“Agent 明明有权限却不敢跨主机探测”的问题，并让声明式 Adapter 支持只读 POST。数据模型、事件格式和数据库迁移没有变化，可直接覆盖安装。

## 主要变化

- **跨主机只读探测默认开启**：`academic_probe_source` / `academic_crawl_source` 默认允许任意公开 HTTPS 主机，不再要求逐个往 `probeAllowedHosts` 里加域名；需要收紧时在来源配置设 `probeAllowAnyPublicHost: false`。跨主机仍不携带该域名的 Cookie，私网/回环/元数据地址仍拒绝，页数/深度/字节/时长上限不变。
- **探测间隔改为 10 秒**（每来源 6 次/分钟），不再出现等 20 秒的情况；过早请求仍立即返回剩余等待秒数。
- **声明式 Adapter 支持显式只读 POST**（ADR 0016）：Manifest 可写 `method: "POST"` + JSON `body`（值支持模板，≤16 KB），用 `pageIn` / `offsetIn: "body"` 在 body 内分页；不发送表单编码、multipart 或自定义头。301/302/303 降级为 GET，307/308 才重发 body，每一跳仍重新校验主机与路径。
- **Agent 可用 POST 探测并捕获样本**：`academic_probe_source` 新增 `method` / `body` 参数；POST 样本按 URL+方法+body 精确匹配，GET 与 POST 样本不会互相误用。
- **修复登录误判**：JS/JSON 资源正文里出现 `/login` 不再被当成登录页；只对 HTML 使用标题/正文模式判断。
- 工具数更新为 **24**（新增 `academic_crawl_source`）。

## 升级

数据结构未变，直接替换插件后重启 DSH 即可：

```bash
dsh plugin --profile desktop remove @academic/dsh-plugin @academic/dsh-ui
dsh plugin --profile desktop add \
  @academic/dsh-plugin@0.1.1 \
  @academic/dsh-ui@0.1.1
```

本地 tarball 安装：

```bash
dsh plugin --profile desktop add \
  /path/to/academic-dsh-plugin-0.1.1.tgz \
  /path/to/academic-dsh-ui-0.1.1.tgz
```

> Desktop 使用 link 包时，重建 `lib/` 后必须完全退出并重启 DSH；仅刷新页面不会加载新的工具描述。

## 已知限制

- 声明式 Adapter 不支持表单 POST、multipart、自定义请求头、XPath/XML 与任意 JavaScript。
- 跨主机请求不带其他主机的 Cookie；目标站点若要求单独登录，仍需要为该主机保存会话。
- 超星/智慧树的真实 POST 接口尚未完成端到端同步验证（需要有效会话与真实样本）。
- npm registry 发布仍等待本机 `npm login` 与 `@academic` scope 确认；本版本先通过 GitHub Release 与本地 tarball 分发。
